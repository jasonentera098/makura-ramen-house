# Password Toggle - User Guide

## How to Use the Show/Hide Password Feature

### Quick Overview
Every password field in the IT Helpdesk system now has an **eye icon button** on the right side that lets you show or hide your password.

---

## Visual Guide

### 🔒 Password Hidden (Default)
```
┌─────────────────────────────────────┐
│ Password *                          │
├─────────────────────────────────────┤
│ •••••••••                      👁   │  ← Click the eye icon
└─────────────────────────────────────┘
```
- Your password is hidden with bullet points (•••)
- The eye icon (👁) means "click to show"
- This is the default, secure state

### 👁 Password Visible
```
┌─────────────────────────────────────┐
│ Password *                          │
├─────────────────────────────────────┤
│ MyPassword123!              👁‍🗨   │  ← Click to hide again
└─────────────────────────────────────┘
```
- Your password is shown as plain text
- The eye with slash (👁‍🗨) means "click to hide"
- You can verify you typed it correctly

---

## Where You'll Find It

### 1. Login Screen
**Location:** Main login window

**What you'll see:**
- Username field
- Password field with eye icon
- Login button

**How to use:**
1. Type your username
2. Type your password (hidden by default)
3. Click the eye icon if you want to see what you typed
4. Click again to hide it
5. Click "LOG IN"

---

### 2. Add New User
**Location:** Admin → Users → Add User button

**What you'll see:**
- Full Name field
- Username field
- Password field with eye icon
- Password strength indicator
- Role dropdown
- Department dropdown (for employees)
- Contact number field

**How to use:**
1. Fill in user details
2. Type a password (hidden by default)
3. Watch the password strength indicator
4. Click the eye icon to verify your password
5. Click again to hide it
6. Click "Save"

**Note:** The password strength indicator works whether the password is hidden or visible!

---

### 3. Edit User
**Location:** Admin → Users → Select user → Edit button

**What you'll see:**
- Same as Add User
- Password field is optional (leave blank to keep current password)

**How to use:**
1. Edit user details as needed
2. If changing password, type new password
3. Use eye icon to verify new password
4. Click "Save"

---

### 4. Change Password
**Location:** Any user → Change Password menu

**What you'll see:**
- **Current Password** field with eye icon
- **New Password** field with eye icon
- **Confirm New Password** field with eye icon
- Password strength indicator

**How to use:**
1. Type your current password
   - Click eye icon to verify if needed
2. Type your new password
   - Watch the strength indicator
   - Click eye icon to verify
3. Type new password again to confirm
   - Click eye icon to verify it matches
4. Click "Save Password"

**Pro Tip:** You can show/hide each password field independently!

---

## Common Scenarios

### ✅ Scenario 1: "I'm not sure if I typed my password correctly"
**Solution:**
1. Click the eye icon (👁)
2. Check if the password is correct
3. Click the eye icon again (👁‍🗨) to hide it

### ✅ Scenario 2: "I want to make sure my new password meets requirements"
**Solution:**
1. Type your password
2. Click the eye icon to see it
3. Check the password strength indicator
4. Verify it has:
   - At least 8 characters
   - Uppercase letter
   - Lowercase letter
   - Number
   - Special character
5. Click eye icon to hide when done

### ✅ Scenario 3: "I want to verify my passwords match"
**Solution (Change Password page):**
1. Type new password in "New Password" field
2. Click eye icon to show it
3. Type same password in "Confirm New Password" field
4. Click eye icon to show it
5. Verify they match exactly
6. Hide both when done

### ✅ Scenario 4: "Someone is looking over my shoulder"
**Solution:**
1. Make sure password is hidden (eye icon should be 👁)
2. If visible, click the eye icon to hide it immediately
3. Password is secure by default

## Tips & Best Practices

### 🔐 Security Tips
1. **Always hide your password** when others are nearby
2. **Use the toggle** to verify your password in private
3. **Don't leave password visible** when stepping away
4. Password is **hidden by default** for your security

### 💡 Usability Tips
1. **Use the toggle** when creating strong passwords
2. **Verify special characters** are typed correctly
3. **Check password strength** while visible
4. **Confirm passwords match** before saving

### ⚡ Quick Tips
1. **Hover over the eye icon** to see "Show/Hide Password" tooltip
2. **Icon changes** to show current state (👁 = hidden, 👁‍🗨 = visible)
3. **Works with validation** - strength indicator updates in both modes
4. **Independent toggles** - each password field has its own button

3. Press **Enter** or **Space** to toggle visibility
4. Press **Tab** to continue to next field

### Accessibility
- Screen readers announce "Show/Hide Password" button
- Button has clear tooltip

## Troubleshooting

### ❓ "I don't see the eye icon"
**Check:**
- Make sure you're looking at a password field
- Icon is on the right side of the field
- Try hovering over the right side of the password field

### ❓ "The eye icon doesn't work"
**Try:**
1. Click directly on the eye icon
2. Make sure the field is not disabled
3. Refresh the page/window

### ❓ "My password disappeared when I toggled"
**Don't worry:**
- Your password is still there
- It's just switching between hidden and visible
- Try toggling again to see it

### ❓ "Password strength indicator disappeared"
**This is normal:**
- Indicator only shows when you're typing
- It will reappear when you type more
- Works in both hidden and visible modes
